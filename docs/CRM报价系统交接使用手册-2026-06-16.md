# CRM 报价系统交接使用手册

版本日期：2026-06-16  
线上地址：https://glass.neiceban.com/  
适用对象：老板、管理员、销售、后续维护人员

## 1. 系统定位

本系统是一个 CRM 客资管理 + 足球场报价系统，核心作用是把客户、跟进、报价、成交、产品价格、辅料价格和账号权限放在同一个系统里管理。

系统上线后：

| 数据类型 | 存储位置 | 说明 |
| --- | --- | --- |
| 账号、权限、客户、产品、辅料 | Cloudflare D1 数据库 | 用于长期保存业务数据 |
| 产品图片、辅料图片、合同附件 | Cloudflare R2 存储 | 用于保存上传文件 |
| 页面和接口 | Cloudflare Pages + Hono | 用户访问网站和接口 |
| 报价 PDF | Cloudflare Browser Rendering | 用于服务器生成 PDF |

系统健康检查地址：

`https://glass.neiceban.com/api/health`

如果返回 `d1/r2/pdf` 都是 `ok: true`，说明数据库、图片存储和 PDF 服务都已正常绑定。

## 2. 主要页面

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 登录页 | `/login` | 输入账号密码进入系统 |

## 3. 登录和账号规则

1. 打开 `https://glass.neiceban.com/`。
2. 系统会自动跳到登录页。
3. 输入后台创建的账号和密码。
4. 点击 `登录系统`。

账号规则：

- 账号不能自己注册，只能由主账号或有账号管理权限的人在后台添加。
- 子账号可以修改自己的密码。
- 主账号或管理员可以在后台重置其他账号密码。
- 系统不主动记住账号密码；如果浏览器自动填充，是浏览器自己的保存密码功能。
- 当前网页刷新后登录状态保留；关闭网页后重新进入通常需要重新登录。

## 4. 权限说明

后台账号权限是系统安全的核心。不同账号看到的数据和能做的操作不同。

| 权限名称 | 具体代表什么 | 没有权限时会怎样 |
| --- | --- | --- |
| 启用 | 是否允许账号登录 | 不能登录系统 |
| 产品管理 | 修改、删除、批量删除产品；维护产品图片、价格、加针价格 | 后台不能维护产品 |
| 辅料管理 | 修改、删除、批量删除辅料；维护辅料图片和价格 | 后台不能维护辅料 |
| 产品导入 | 导入产品 Excel、下载产品模板 | 不能批量导入产品 |
| 账号管理 | 新增账号、修改角色、分配权限、重置密码 | 不能管理账号 |
| 看全部客户 | 能查看所有销售的客户 | 只能看到自己的客户 |
| 导入客户 | 能导入客资 Excel | 不能导入客资 |
| 导出客户 | 能导出完整客资表 | 只能下载模板，不能导出客户数据 |
| 删除客户 | 能删除单个或批量删除客户 | 看不到删除或批量删除操作 |
| 回收站恢复 | 能从回收站恢复 7 天内删除的数据，查看操作记录 | 不能恢复数据 |
| 报价导出 | 能导出报价单 PDF | 不能导出正式报价单 |
| 临时改价 | 报价时可以临时修改单价 | 只能使用后台默认价格 |

角色建议：

| 角色 | 建议用途 |
| --- | --- |
| 主账号 | 老板或最高管理员，能看到全部数据并管理所有功能 |
| 管理员 | 负责产品、辅料、账号、客资分配和数据维护 |
| 报价员/销售 | 日常跟进客户、生成报价、维护自己的客户 |
| 只读 | 临时查看数据，不建议作为日常销售账号 |

## 5. CRM 首页使用

CRM 首页主要用于老板和销售快速看数据。

主账号或管理员可见：

- 可见客户数量
- 昨日成交金额
- 本月成交金额
- 成交客户数
- 每月成交额曲线
- 每日新增客资曲线
- 本月成交排名
- 客资分配
- 客户列表预览

普通销售可见：

- 自己的客户数据
- 自己相关的成交数据
- 本月成交排行
- 最近客户预览

每日新增客资曲线说明：

| 选项 | 含义 |
| --- | --- |
| 全部 | 所有新增客资 |
| 统一新增 | 管理员或主账号统一分配给销售的客资 |
| 自来新增 | 销售自己新建或导入到自己名下的客资 |

客户列表预览：

- 首页只显示最近新增或最近修改的客户。
- 完整列表请点击 `客户管理`。

## 6. 客资分配

位置：CRM 首页右侧 `客资分配`。

### 单条分配

可以填写：

- 客户名称
- 联系人
- 电话
- 微信号
- 抖音账号来源
- 成交属性：高/中/低/无效
- 客户属性：B端/C端
- 地址
- 意向等级
- 意向使用场景
- 数量
- 使用时间
- 客户情况沟通内容
- 分配给哪个销售

最少只填电话或微信，也可以先分配。

### 批量分配

用于把一个 Excel 表里的客资统一分给某个销售。

操作步骤：

1. 在 `批量分配` 位置选择销售人员。
2. 点击上传表格。
3. 选择客资 Excel。
4. 系统会把有效客资追加导入，并归属到选中的销售。

导入规则：

- 导入是追加，不会删除之前的客资。
- 没有客户名称、没有联系方式的空白行不会导入。
- 只有序号但没有客户名称或联系方式的行不会导入。
- 表格里的跟踪反馈会同步到客户跟进记录。
- 普通销售如果有导入权限，导入后的客户归自己。

## 7. 客户管理页面

地址：`/crm/customers`

客户管理用于看完整客资表。

常用功能：

- 搜索客户、联系方式、来源、地址、沟通内容。
- 按状态筛选：全部、未成交、已成交、无效。
- 今日跟进：今天新增过跟进记录或提醒的客户。
- 今日新增：今天新建或导入的客户。
- 重点关注：点击星标后的客户。
- 年份和月份筛选。
- 新增客户。
- 导入客资。
- 下载导入模板。
- 导出客资。
- 批量删除。
- 批量转移负责人。
- 寄样和物流单号记录。

视角说明：

- 主账号或有 `看全部客户` 权限的人，可以选择查看全部客户或某个销售的客户。
- 普通销售只能看到自己的客户。

重点关注：

- 点击客户行后面的空心星标，会变成实心星标。
- 点击 `重点关注` 筛选，可以只看重点客户。

寄样：

- 点击 `寄样` 后可以填写样品规格和样品单号。
- 有单号后可用于后续物流查询或人工跟踪。

## 8. 新建客户

位置：客户管理页面 `新增客户`。

操作步骤：

1. 点击 `新增客户`。
2. 系统弹出新建客户窗口。
3. 填写客户资料。
4. 点击右下角 `保存客户`。

注意：

- 不点击保存，客户不会添加成功。
- 如果关闭窗口前未保存，系统会提示有未保存内容。

## 10. 跟进记录和提醒

### 跟进记录

可操作：

- 新增跟进
- 修改跟进内容
- 删除跟进
- 修改跟进日期

跟进记录日期会显示成一个日期块，上面显示年份，下面显示月份和日期。

### 添加提醒

适合客户说“过几天联系我”或“某天再联系”。

操作步骤：

1. 点击 `+ 添加提醒`。
2. 选择提醒日期。
3. 填写提醒内容。
4. 保存提醒。

提醒规则：

- 登录后如果有当天提醒，会在系统内提示。
- 客户管理里的 `今日跟进` 会包含今天新增提醒或新增跟进的客户。

## 11. 报价记录和成交

在客户详情右侧切换到 `报价记录`。

可操作：

- 查看历史报价。
- 查看报价单 PDF。
- 上传合同。
- 标记已成交。
- 填写成交价。
- 修改报价日期。

勾选 `已成交` 后：

- 客户状态会变成已成交。
- 成交金额会计入首页统计和本月成交排行。
- 合同不是必须上传，但建议成交后上传，便于后续查证。

## 12. 新建报价流程

### 从客户详情进入

1. 打开客户详情。
2. 点击 `新建报价`。
3. 系统进入报价页面，并带入当前客户。
4. 选择产品和辅料。
5. 生成报价单。
6. 点击 `返回当前客户`，报价记录会保存在客户详情里。

### 直接进入报价系统

1. 点击 `进入报价` 或打开 `/quote`。
2. 手动填写客户和项目信息。
3. 选择产品、辅料和施工项。
4. 导出报价单。

## 13. 报价系统使用

报价页面主要包含：

- 基础信息
- 场地面积
- 草坪产品
- 报价参数显示
- 施工辅料
- 实时价格
- 报价单预览和导出

### 场地面积

填写场地面积后：

- 报价面积跟随场地面积。
- 辅料用量按面积计算。
- 运费、施工费按面积计算。
- 总价按面积和单价自动计算。

### 产品筛选

可按以下条件筛选：

- 产品类型
- 草高
- 密度
- 磅重
- 搜索货号、名称、草高、密度、基布、价格

草高支持中文毫米搜索，例如：

- `50mm`
- `50MM`
- `50毫米`

### 产品类型

产品类型由后台产品数据自动生成。

例如导入表格中出现新类型 `高尔夫草`，导入成功后，报价页面会自动出现该类型。

### 加针功能

后台产品里可以设置 `加针价格`。

报价时：

1. 先把产品加入报价。
2. 在报价明细中填写加针数和每针加价。
3. 系统自动计算：原单价 + 加针数 × 每针加价。
4. 导出的报价单只显示最终针数。

示例：

- 原密度：15针
- 加针：3针
- 报价单显示：18针

### 报价参数显示

可以勾选是否在报价单显示：

- 草高
- DTEX
- 草丝
- 密度
- 针排
- 底布
- 抗衰老

未勾选的参数不会显示在报价单中。

## 14. 辅料和套餐

辅料包含：

- 橡胶颗粒
- 石英砂
- 减震垫
- 单组胶水
- 双组胶水
- 接缝布
- 白草坪
- 施工运费

辅料规则：

- 石英砂价格按吨维护，例如 300/吨。
- 颗粒每袋 25kg，不足一袋按一袋计算。
- 例如需要 20kg，按 25kg 算；需要 110kg，按 125kg 算。
- 辅料默认跟随报价面积计算。
- 辅料可以临时改价，也可以在后台修改默认价格。

套餐：

- 后台可维护套餐。
- 报价页面选择套餐后，会自动带出对应辅料。
- 套餐价格和辅料价格都可以在后台维护。

## 15. 报价单导出

报价单支持：

- PDF 预览
- PDF 下载
- 手机端预览后下载

导出注意：

- PDF 按 A4 格式生成。
- 报价单只展示给客户看的信息。
- 不展示内部备注、后台管理字段和不需要给客户看的内容。
- 手机 Safari 对直接下载文件支持不稳定，所以手机端会先打开预览页，再点保存或下载。

如果手机端下载空白：

1. 先在预览页确认表格显示完整。
2. 不要直接复制浏览器临时地址。
3. 点击页面内的保存或下载按钮。
4. 如果仍异常，换 Chrome 或微信外部浏览器再试。

## 16. 图片管理

图片分为默认图片和临时图片。

### 默认图片

位置：管理后台。

适用：

- 产品默认图片
- 辅料默认图片

默认图片会跟随产品或辅料保存，后续导出报价单时自动显示。

### 临时图片

位置：报价页面。

适用：

- 某一次报价临时替换图片。
- 只对当前报价有效。
- 不会覆盖后台默认图片。

上线后图片存放在 Cloudflare R2，不会因为换电脑丢失。

## 17. 管理后台

地址：`/admin`

主要功能：

- 产品管理
- 辅料管理
- 账号权限
- 回收站/操作记录

### 产品管理

可维护：

- 货号
- 类型
- 名称
- 草高
- DTEX
- 草丝
- 密度
- 针排
- 底布
- 抗衰老

### 辅料管理

可维护：

- 名称
- 规格
- 价格
- 用量规则
- 默认图片
- 套餐

辅料支持单个删除和批量删除。

### 账号权限

可维护：

- 新增账号
- 修改账号名称
- 修改角色
- 勾选权限
- 启用/停用账号
- 重置密码

子账号修改自己的密码后，会同步到主账号后台看到的账号信息里。

### 回收站/操作记录

规则：

- 删除的客户、产品、辅料会进入回收站。
- 回收站和操作记录保留 7 天。
- 有 `回收站恢复` 权限的人可以恢复。

## 19. 手机端使用

手机端原则是简单使用：

- 客户管理只显示关键字段。
- 报价页减少大块统计模块。
- 产品主要通过搜索和筛选选择。
- 报价单先预览，再下载。
- 手机端不建议做大量后台维护，后台维护建议用电脑。

手机端常用流程：

1. 登录系统。
2. 进入客户管理。
3. 查看或新增客户。
4. 进入客户详情写跟进。
5. 需要报价时点击新建报价。
6. 在报价页选择产品和辅料。
7. 预览报价单。
8. 下载 PDF 或返回客户详情。

## 20. 常见问题

### 1. 登录慢

可能原因：

- 首次登录需要同步云端客户、产品、账号数据。
- 手机网络较慢。
- 浏览器缓存较多。

处理方式：

- 等待几秒。
- 刷新一次。
- 换 Chrome 或网络再试。

### 2. 账号密码正确但登录失败

检查：

- 账号是否停用。
- 密码是否被管理员重置。
- 是否输入了浏览器自动填充的旧密码。
- 后台账号是否已同步到云端。

### 3. 普通销售看不到全部客户

这是正常权限设计。普通销售只能看到自己的客户。

如果需要查看全部客户，需要主账号勾选 `看全部客户`。

### 4. 普通销售不能导出客户

这是正常权限设计。

如果需要导出，需要主账号勾选 `导出客户`。

### 5. 导入后出现未命名客户

通常是表格中没有客户名称，但有联系方式。

如果客户名称和联系方式都没有，系统会跳过，不导入。

### 6. 报价单图片没有显示

检查：

- 后台是否上传默认图片。
- 报价时是否临时上传图片。
- 网络是否能访问 R2 图片。

### 7. PDF 导出异常

检查：

- 打开 `/api/health` 看 PDF 是否为 `bound`。
- 手机端先预览再下载。
- 电脑端建议使用 Chrome。

### 8. 数据是否丢失

正常情况下不会因为换电脑丢失，因为数据在 D1 和 R2。

如果页面看起来数据不对：

- 先刷新页面。
- 确认登录账号权限。
- 确认是否切换了客户视角。
- 检查是否被删除进入回收站。

## 21. 日常工作流程建议

### 销售每天流程

1. 登录系统。
2. 查看自己的客户。
3. 处理提醒事项。
4. 新增客户或接收分配客资。
5. 在客户详情写跟进记录。
6. 需要报价时点击新建报价。
7. 报价完成后返回客户详情。
8. 成交后勾选已成交，填写成交价。
9. 有合同就上传合同。

### 管理员每天流程

1. 查看首页成交数据和新增客资。
2. 分配新客资。
3. 检查客户导入是否成功。
4. 管理产品和辅料价格。
5. 处理误删数据恢复。
6. 管理账号权限。

### 产品价格维护流程

1. 进入管理后台。
2. 打开产品管理。
3. 修改产品价格、阶梯价格或加针价格。
4. 上传或修改默认图片。
5. 保存后到报价页面测试。
6. 确认报价单显示正常。

### 辅料价格维护流程

1. 进入管理后台。
2. 打开辅料管理。
3. 修改每吨价格、用量规则或套餐。
4. 保存后到报价页面测试用量和小计。

## 22. 交接清单

交接时建议确认：

- 主账号账号密码。
- 管理员账号名单。
- 每个销售账号权限。
- 谁能导出客户。
- 谁能删除客户。
- 产品导入模板。
- 客资导入模板。
- 当前报价单格式。
- Cloudflare 账号。
- GitHub 仓库地址。
- 域名 `glass.neiceban.com` 是否正常。
- `/api/health` 是否正常。

## 23. 维护提醒

- 不要随意删除主账号。
- 不要把普通销售设置成主账号。
- 离职人员客户要先批量转移给新人。
- 产品价格大改前建议先导出一份产品表备份。
- 客资大批量导入前建议先用 3 到 5 行测试。
- 报价单格式改动后，要电脑和手机都测试一次。
- 如果 GitHub 推送失败，多数是当前网络连不上 GitHub，不代表线上系统有问题。
