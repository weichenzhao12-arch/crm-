# CRM 报价系统上线前完整测试清单

## 1. 登录与账号

- 主账号可以登录、退出、重新登录。
- 管理员账号可以登录，普通销售账号可以登录。
- 销售账号只能修改自己的密码，修改后主账号后台能看到新密码。
- 禁用账号后，该账号不能继续登录。
- 登录后刷新当前网页不需要重新登录；关闭浏览器重新进入需要重新登录。

## 2. 权限

- 主账号可以看到全部客户、全部销售排行、客户分配、管理后台、导入导出、删除恢复。
- 管理员按后台勾选权限生效。
- 普通销售只能看到自己的客户。
- 普通销售不能导出客资，只能下载导入模板。
- 没有删除权限的账号，客户列表不显示删除和批量删除。
- 没有产品/辅料权限的账号，不允许维护产品或辅料。

## 3. 客户与客资

- 新建客户弹窗打开后，不点保存直接关闭，会提示未保存。
- 保存客户后自动关闭弹窗，客户出现在客户管理列表。
- 电话、微信、联系方式重复时，系统会提示可能重复客户。
- 客户列表可按全部、重点关注、今日跟进、今日新增、未成交、已成交、无效筛选。
- 主账号切换销售视角后，只显示对应销售客户。
- 重点关注星标可切换，重点关注筛选能筛出客户。
- 客户删除后进入回收站，7 天内可恢复。

## 4. 导入导出

- 客资表格导入时，空白行不导入。
- 导入客资不会清空原有客户。
- 导入时如果发现可能重复客户，会弹出确认。
- 导入表里的跟进反馈会同步到客户跟进记录。
- 有导出权限的账号可以导出客资；无权限账号只能下载模板。
- 产品标准表格可以导出，再按格式导入。

## 5. 跟进、提醒、寄样

- 客户详情可以新增跟进记录。
- 跟进记录可以修改、删除。
- 添加提醒后，登录首页会提醒。
- 今日跟进筛选包含今天新增的跟进和今天提醒的客户。
- 寄样信息可以填写样品规格、样品单号。
- 填写样品单号后可以打开物流查询。

## 6. 报价

- 从客户详情点击新建报价，生成报价后能返回当前客户。
- 客户报价记录显示第几版报价。
- 一个客户多次报价，报价记录都保留。
- 勾选已成交后，客户状态变成已成交，成交价计入本月成交排行。
- 报价记录可以上传合同。
- PDF 预览正常，下载 PDF 非空白。
- 手机端报价 PDF 可以预览并保存。

## 7. 商品和辅料

- 后台产品可以新增、修改、删除、批量删除。
- 后台辅料可以新增、修改、删除、批量删除。
- 产品和辅料默认图片可以上传、替换、清除。
- 修改产品价格、加针价格、辅料价格后，操作记录里能看到记录。
- 产品导入时出现新类型，报价页面筛选里能显示新类型。
- 草高带“毫米”等中文单位时，搜索和筛选能正常匹配。

## 8. 首页统计

- 主账号首页能看到全部销售排行。
- 普通销售也能看到本月成交排行，但客户数据仍只看自己的。
- 主账号能看到每日新增客资曲线。
- 每日新增客资曲线支持全部、统一新增、自来新增切换。
- 客户列表预览显示最近新增或修改的 5 条。

## 9. 手机端

- 手机端客户列表只显示客户名称、联系方式、跟进人。
- 手机端客户详情能查看客户、添加跟进、切换报价记录。
- 手机端报价页不显示复杂后台维护入口。
- 手机端选择商品或辅料后，当前位置能看到小计。
- 手机端没有横向滑轨挡住主要操作。

## 10. 数据安全

- D1 数据库有客户、产品、辅料、回收站、操作记录镜像表。
- R2 图片上传后刷新页面仍能显示。
- 回收站和操作记录只保留 7 天。
- 发布前先备份当前版本。
