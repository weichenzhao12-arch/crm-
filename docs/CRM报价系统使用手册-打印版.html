CRM 报价系统
详细使用手册

用于交接系统日常使用、客户管理、报价生成、后台维护、账号权限、云端存储和后续维护事项。建议新账号培训时按本手册顺序演示一遍。

系统地址https://glass.neiceban.com/项目名称CRM 报价系统生成时间2026/6/9 11:29:33适用对象主账号、管理员、销售人员、后续维护人员

系统架构总览

前台负责操作，接口负责校验和保存，D1 保存业务数据，R2 保存图片和附件，Cloudflare Pages 负责对外访问。

客户与报价业务流

从新增客资到分配、跟进、报价、成交归档，每一步都有对应页面和权限控制。

权限与数据可见范围

主账号看全部并管理账号；管理员按勾选权限操作；普通销售默认只看自己的客户。

报价生成与价格逻辑

产品支持阶梯价格、加针价格、辅料用量换算、运费施工按平方、PDF/Word 导出和客户报价记录保存。

数据同步与备份

系统上线后，账号、客户、产品、价格等保存到 D1；图片和附件保存到 R2；代码和手册同步到 GitHub。

版本日期：2026-06-09

系统地址：https://glass.neiceban.com/

1. 系统用途

本系统用于管理客户客资、销售跟进、报价单生成、产品和辅料价格维护、账号权限管理。上线后数据存储在 Cloudflare D1 数据库，图片存储在 Cloudflare R2，用户登录后才能进入系统。

系统主要包含 4 个页面：

页面地址主要用途
登录页/login输入账号密码进入系统
CRM 首页/ 或 /crm查看销售数据、分配客资、客户预览
客户管理/crm/customers查看完整客户列表、导入导出、筛选、批量操作
客户详情/crm/customer/客户ID编辑客户资料、跟进、提醒、报价记录
报价系统/quote选择产品和辅料，生成报价单、PDF、Word
管理后台/admin管理产品、辅料、账号权限、默认图片

2. 登录和账号

1打开 https://glass.neiceban.com/。

2系统会跳转到登录页面。

3输入后台创建的账号和密码。

4点击 登录系统。

注意事项：

  • 账号不能自行注册，必须由主账号或有账号管理权限的人在后台添加。
  • 子账号可以登录后修改自己的密码。
  • 如果登录后页面数据加载较慢，通常是因为系统正在同步云端客户、产品、账号数据。
  • 如果浏览器自动填充旧密码，建议清除浏览器保存密码，或手动重新输入。

3. 权限说明

后台账号有角色和单独权限。角色会给一套默认权限，也可以手动勾选调整。

权限项含义典型使用对象
启用是否允许该账号登录所有账号
产品管理可以维护草坪产品、导入产品表、上传产品图片主账号、管理员
辅料管理可以维护辅料、套餐、默认图片和价格主账号、管理员
数据导入管理可以导入产品表、客资表等批量数据主账号、管理员
账号/客户管理可以新增账号、设置权限、查看和分配全部客户主账号、管理员
报价/客户导出可以导出报价单或客户表主账号、管理员或指定人员
报价临时改价可以在报价时临时修改价格，但不改变后台默认价格销售、报价员

角色建议：

角色建议说明
主账号老板或系统最高管理员，可以看到全部数据、删除客资、管理账号
管理员可协助管理产品、辅料、导入数据、分配客资
报价员/销售只看自己的客户，能新建客户、跟进、报价，通常不能导出全部客户
只读只查看，不建议作为日常销售账号

5. 客资分配

位置：CRM 首页右侧 客资分配。

单条分配

可填写的信息包括：

  • 客户名称
  • 联系人
  • 电话
  • 微信号
  • 抖音账号来源
  • 成交属性：高/中/低/无效
  • 客户属性：B端/C端
  • 地址
  • 意向等级
  • 意向使用场景
  • 数量（平方）
  • 使用时间
  • 客户情况沟通内容
  • 分配给哪个销售

最少可以只填电话或微信，然后选择销售，点击 分配客资。

批量分配

位置：CRM 首页 客资分配 下方的 批量分配。

操作步骤：

1在 批量分配 区域选择销售人员。

2点击 上传表格。

3选择 Excel 客资表。

4系统会把表格内有效客资统一分配给选中的销售。

规则：

  • 导入是追加，不会删除原有客资。
  • 表格中只有序号、没有客户名称/联系人/电话/微信/联系方式的空白行不会导入。
  • 导入后客户负责人会变成选择的销售人员。

6. 客户管理页面

地址：/crm/customers

客户管理页面用于横向查看完整客资表。

主要功能：

  • 查看全部客户或个人客户
  • 搜索客户、联系方式、来源、地址、沟通内容
  • 按状态筛选：全部、未成交、已成交、无效
  • 今日跟进
  • 今日新增
  • 重点关注
  • 年份、月份筛选
  • 新建客户
  • 导入客资
  • 下载模板
  • 导出客资
  • 批量删除
  • 批量转移客户负责人
  • 寄样和物流跟踪

客户视角

主账号或有管理权限账号可以选择：

  • 全部客户
  • 某个销售人员的客户

普通销售只能看到自己的客户。

筛选说明

筛选含义
全部显示当前权限下所有客户
未成交不包含已成交和无效
已成交客户状态为已成交
无效客户状态为无效
今日跟进今天新增过跟进记录或提醒的客户
今日新增今天新建或导入的客户
重点关注点击星标后的重点客户

新建客户

1点击 新增客户。

2在弹窗里填写客户资料。

3点击右下角 保存客户。

注意：

  • 不点击保存，客户不会添加成功。
  • 如果未保存直接关闭，会出现未保存提示。

导入客资

1点击 导入客资。

2选择 Excel 表格。

3系统会追加导入有效行。

导入规则：

  • 空白行不会导入。
  • 只有序号但没有客户名称/联系方式的行不会导入。
  • 跟踪反馈会同步到客户跟进记录。
  • 导入不会清空之前客户。

导出客资

只有主账号、管理员或有 报价/客户导出 权限的账号可以导出完整客资。

普通销售：

  • 不能导出客户资料。
  • 只能下载导入模板。

批量删除

主账号或管理员可以批量删除客资。

注意：

  • 删除后无法恢复。
  • 普通销售没有删除客资权限。

批量转移负责人

用于人员离职或客户重新分配。

操作：

1勾选需要转移的客户。

2选择新负责人。

3点击批量转移。

8. 新建报价流程

有两种进入方式：

从客户详情进入

1打开客户详情。

2点击 新建报价。

3系统进入报价页面，并自动带入当前客户。

4生成或导出报价单后，可点击 返回当前客户。

5报价记录会同步保存到该客户下。

直接进入报价系统

1点击 进入报价 或打开 /quote。

2手动填写客户信息和报价内容。

3导出报价单。

9. 报价系统使用

报价页面主要分为：

  • 报价基础信息
  • 草坪产品
  • 报价单参数显示
  • 施工辅料
  • 实时价格
  • 报价单预览/导出

场地面积

可输入场地面积。报价面积、辅料用量、运费、施工费都会按该面积计算。

产品筛选

可按以下条件筛选：

  • 产品类型
  • 草高
  • 密度
  • 磅重
  • 搜索货号、名称、草高、密度、基布、价格

草高支持类似：

  • 50mm
  • 50MM
  • 50毫米

加针功能

后台可设置产品默认 加针价格。

生成报价时：

1先把产品加入右侧 产品明细。

2在产品明细里填写：

  • 加针数
  • 每针加价

3单价会自动变为：原阶梯单价 + 加针数 × 每针加价。

4导出的报价单只显示最终针数。

示例：

  • 原密度：15针
  • 加针数：3
  • 报价单显示：18针

报价单参数显示

可勾选是否在报价单显示：

  • 草高
  • DTEX
  • 草丝
  • 密度
  • 针排
  • 底布
  • 抗老化

未勾选的参数不会在报价单显示。

辅料报价

辅料包括但不限于：

  • 橡胶颗粒
  • 石英砂
  • 胶水
  • 减震垫
  • 接缝布/连接带
  • 运动白草
  • 其他辅料

辅料可按平方自动计算用量。

颗粒规则：

  • 每袋 25kg。
  • 如果需要 20kg，按 25kg 计算。
  • 如果需要 110kg，按 125kg 计算。
  • 最终换算为吨计价。

石英砂：

  • 价格按吨计算。

包工包料套餐

可以选择套餐方式，例如辅料 A、辅料 B。套餐也可以在后台维护。

运费和施工费

运费和施工费按输入的平方计算。

可选择：

  • 运费+施工费合并填写
  • 运费、施工费分开填写

后期如需做运费模板，可以继续扩展。

图片

产品和辅料可以有默认图片。

图片来源：

  • 后台上传的默认图片
  • 报价时临时上传替换的图片

导出报价单时会显示对应图片。

10. 报价单导出

支持：

  • PDF
  • Word/RTF
  • 打印

导出格式：

  • A4 页面
  • 按公文排版风格
  • 尽量压缩到一页
  • 总价、税费、产品信息、辅料信息按当前设置显示

注意：

  • 如果没有税费，不显示税费。
  • 如果有税费，显示税费。
  • 导出的报价单里显示的是最终报价结果，不显示后台不需要给客户看的内部信息。

产品价格


报价系统会根据报价面积自动选择对应阶梯单价。

加针价格

后台产品管理中维护 加针价格。

15. 常见问题

1. 登录后反应慢

可能原因：

  • 正在同步云端数据。
  • 网络到 Cloudflare 较慢。
  • 客户数据、图片、产品数据较多。

处理：

  • 等待几秒。
  • 刷新页面。
  • 检查网络。

2. 页面显示旧内容

处理：

  • Chrome 按 Ctrl + F5 强制刷新。
  • 退出登录后重新登录。
  • 如仍不行，让管理员检查是否已部署最新版本。

3. 新增账号登录不进去

检查：

  • 账号是否启用。
  • 密码是否正确。
  • 是否已经保存后台数据。
  • 是否存在中文账号输入法空格。

4. 导入后客户变成未命名客户

原因：

  • 表格行没有客户名称，也没有联系方式。

现在系统会过滤完全空白行，但如果联系方式列名不规范，可能无法识别。

建议使用系统下载的模板。

5. 报价单没有显示图片

检查：

  • 后台产品或辅料是否上传默认图片。
  • 报价时是否临时上传图片。
  • 图片是否上传成功。
  • 网络是否能访问 R2 图片。

6. 普通销售看不到全部客户

这是正常权限设计。

普通销售只能看到自己的客户，主账号或管理员可查看全部。

7. 普通销售不能导出客资

这是正常权限设计。

普通销售只能下载导入模板，不能导出完整客户资料。

16. 日常建议流程

销售日常流程

1登录系统。

2查看自己的客户。

3新增客户或接收分配客资。

4在客户详情中记录跟进。

5需要报价时点击 新建报价。

6生成报价单。

7返回客户详情查看报价记录。

8成交后勾选已成交，填写成交价。

9如有合同，上传合同。

管理员日常流程

1登录系统。

2查看首页成交数据和新增客资。

3分配新客资。

4批量导入客资。

5检查销售成交排名。

6更新产品价格和辅料价格。

7管理账号权限。

产品价格维护流程

1进入管理后台。

2打开产品管理。

3搜索货号或类型。

4修改阶梯价格、加针价格、抗老化等。

5上传或更换默认图片。

6点击保存后台数据。

7到报价页面测试价格是否正确。

17. 交接注意事项

交接给新人员时，建议同时交接：

  • 正式系统网址
  • 主账号和临时密码
  • Cloudflare 登录账号
  • GitHub 仓库地址
  • 产品导入模板
  • 客资导入模板
  • 当前权限设置说明
  • 谁负责维护产品价格
  • 谁负责分配客资
  • 谁有导出客户权限

安全建议：

  • 主账号密码不要多人共用。
  • 给每个销售单独账号。
  • 离职人员及时禁用账号。
  • 离职人员客户用批量转移给新负责人。
  • 不要把 Cloudflare API 令牌公开发给无关人员。

18. 最简培训话术

给销售培训时可以这样讲：

1先登录系统。

2客户都在客户管理里。

3每天跟进客户后，进客户详情写跟进记录。

4需要报价就点新建报价。

5报价完成后回到客户详情，报价记录会保存。

6成交后在报价记录里勾选已成交，填写成交价。

7客户要过几天联系，就添加提醒。

8不会操作的地方先不要乱删，找管理员处理。
