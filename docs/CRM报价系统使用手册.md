# CRM 报价系统使用手册

版本日期：2026-06-09  
系统地址：https://glass.neiceban.com/

## 1. 系统用途

本系统用于管理客户客资、销售跟进、报价单生成、产品和辅料价格维护、账号权限管理。上线后数据存储在 Cloudflare D1 数据库，图片存储在 Cloudflare R2，用户登录后才能进入系统。

系统主要包含 4 个页面：

| 页面 | 地址 | 主要用途 |
| --- | --- | --- |
| 登录页 | `/login` | 输入账号密码进入系统 |
| CRM 首页 | `/` 或 `/crm` | 查看销售数据、分配客资、客户预览 |
| 客户管理 | `/crm/customers` | 查看完整客户列表、导入导出、筛选、批量操作 |
| 客户详情 | `/crm/customer/客户ID` | 编辑客户资料、跟进、提醒、报价记录 |
| 报价系统 | `/quote` | 选择产品和辅料，生成报价单、PDF、Word |
| 管理后台 | `/admin` | 管理产品、辅料、账号权限、默认图片 |

## 2. 登录和账号

1. 打开 `https://glass.neiceban.com/`。
2. 系统会跳转到登录页面。
3. 输入后台创建的账号和密码。
4. 点击 `登录系统`。

注意事项：

- 账号不能自行注册，必须由主账号或有账号管理权限的人在后台添加。
- 子账号可以登录后修改自己的密码。
- 如果登录后页面数据加载较慢，通常是因为系统正在同步云端客户、产品、账号数据。
- 如果浏览器自动填充旧密码，建议清除浏览器保存密码，或手动重新输入。

## 3. 权限说明

后台账号有角色和单独权限。角色会给一套默认权限，也可以手动勾选调整。

| 权限项 | 含义 | 典型使用对象 |
| --- | --- | --- |
| 启用 | 是否允许该账号登录 | 所有账号 |
| 产品管理 | 可以维护草坪产品、导入产品表、上传产品图片 | 主账号、管理员 |
| 辅料管理 | 可以维护辅料、套餐、默认图片和价格 | 主账号、管理员 |
| 数据导入管理 | 可以导入产品表、客资表等批量数据 | 主账号、管理员 |
| 账号/客户管理 | 可以新增账号、设置权限、查看和分配全部客户 | 主账号、管理员 |
| 报价/客户导出 | 可以导出报价单或客户表 | 主账号、管理员或指定人员 |
| 报价临时改价 | 可以在报价时临时修改价格，但不改变后台默认价格 | 销售、报价员 |

角色建议：

| 角色 | 建议说明 |
| --- | --- |
| 主账号 | 老板或系统最高管理员，可以看到全部数据、删除客资、管理账号 |
| 管理员 | 可协助管理产品、辅料、导入数据、分配客资 |
| 报价员/销售 | 只看自己的客户，能新建客户、跟进、报价，通常不能导出全部客户 |
| 只读 | 只查看，不建议作为日常销售账号 |

## 4. CRM 首页

CRM 首页用于快速查看整体情况。

主账号或有管理权限账号可以看到：

- 可见客户数量
- 昨日成交金额
- 本月成交金额
- 成交客户数
- 每月成交额曲线
- 每日新增客资曲线
- 本月成交排名
- 客资分配表单
- 客户列表预览

普通销售账号可以看到：

- 自己的客户数据
- 自己相关的成交数据
- 销售成交排名
- 客户列表预览

### 每日新增客资曲线

仅主账号可见。

滑块说明：

| 选项 | 统计口径 |
| --- | --- |
| 全部 | 所有新增客资 |
| 统一新增 | 创建人和负责人不同，例如主账号或管理员分配给销售 |
| 自来新增 | 创建人和负责人相同，例如销售自己新建或导入自己的客户 |

## 5. 客资分配

位置：CRM 首页右侧 `客资分配`。

### 单条分配

可填写的信息包括：

- 客户名称
- 联系人
- 电话
- 微信号
- 抖音账号来源
- 成交属性：高/中/低/无效
- 客户属性：B端/C端
- 地址
- 意向等级
- 意向使用场景
- 数量（平方）
- 使用时间
- 客户情况沟通内容
- 分配给哪个销售

最少可以只填电话或微信，然后选择销售，点击 `分配客资`。

### 批量分配

位置：CRM 首页 `客资分配` 下方的 `批量分配`。

操作步骤：

1. 在 `批量分配` 区域选择销售人员。
2. 点击 `上传表格`。
3. 选择 Excel 客资表。
4. 系统会把表格内有效客资统一分配给选中的销售。

规则：

- 导入是追加，不会删除原有客资。
- 表格中只有序号、没有客户名称/联系人/电话/微信/联系方式的空白行不会导入。
- 导入后客户负责人会变成选择的销售人员。

## 6. 客户管理页面

地址：`/crm/customers`

客户管理页面用于横向查看完整客资表。

主要功能：

- 查看全部客户或个人客户
- 搜索客户、联系方式、来源、地址、沟通内容
- 按状态筛选：全部、未成交、已成交、无效
- 今日跟进
- 今日新增
- 重点关注
- 年份、月份筛选
- 新建客户
- 导入客资
- 下载模板
- 导出客资
- 批量删除
- 批量转移客户负责人
- 寄样和物流跟踪

### 客户视角

主账号或有管理权限账号可以选择：

- 全部客户
- 某个销售人员的客户

普通销售只能看到自己的客户。

### 筛选说明

| 筛选 | 含义 |
| --- | --- |
| 全部 | 显示当前权限下所有客户 |
| 未成交 | 不包含已成交和无效 |
| 已成交 | 客户状态为已成交 |
| 无效 | 客户状态为无效 |
| 今日跟进 | 今天新增过跟进记录或提醒的客户 |
| 今日新增 | 今天新建或导入的客户 |
| 重点关注 | 点击星标后的重点客户 |

### 新建客户

1. 点击 `新增客户`。
2. 在弹窗里填写客户资料。
3. 点击右下角 `保存客户`。

注意：

- 不点击保存，客户不会添加成功。
- 如果未保存直接关闭，会出现未保存提示。

### 导入客资

1. 点击 `导入客资`。
2. 选择 Excel 表格。
3. 系统会追加导入有效行。

导入规则：

- 空白行不会导入。
- 只有序号但没有客户名称/联系方式的行不会导入。
- 跟踪反馈会同步到客户跟进记录。
- 导入不会清空之前客户。

### 导出客资

只有主账号、管理员或有 `报价/客户导出` 权限的账号可以导出完整客资。

普通销售：

- 不能导出客户资料。
- 只能下载导入模板。

### 批量删除

主账号或管理员可以批量删除客资。

注意：

- 删除后无法恢复。
- 普通销售没有删除客资权限。

### 批量转移负责人

用于人员离职或客户重新分配。

操作：

1. 勾选需要转移的客户。
2. 选择新负责人。
3. 点击批量转移。

## 7. 客户详情页

进入方式：

- 在客户列表点击某一行客户。
- 在 CRM 首页客户预览点击客户。

客户详情页分为两部分：

1. 客户资料
2. 跟进记录 / 报价记录

### 客户资料

可维护内容：

- 日期
- 客户名称
- 客户联系方式
- 抖音账号来源
- 成交属性高中低无效
- 客户属性BC端
- 地址
- 数量（平方）
- 使用时间
- 意向等级
- 分配给
- 负责人
- 跟进阶段
- 客户情况沟通内容
- 备注

跟进阶段包括：

- 新客资
- 已报价
- 跟进中
- 已成交
- 无效

### 跟进记录

功能：

- 新增跟进
- 修改跟进内容
- 删除跟进
- 修改跟进日期

跟进记录日期显示为一个小日期块，上面显示年份，下面显示月份和日期。

### 添加提醒

用于客户要求后续联系，例如“三天后联系我”。

操作：

1. 点击 `添加提醒`。
2. 设置提醒日期。
3. 可设置提醒时间、提醒内容、下一步动作。
4. 保存提醒。

提醒显示：

- 登录系统后，如果当天有到期提醒，会弹窗提示。
- 提醒可以标记完成。

### 报价记录

点击右侧滑块切换到 `报价记录`。

可操作：

- 查看客户历史报价
- 上传合同
- 标记已成交
- 输入成交价
- 修改报价日期
- 查看报价单 PDF

选择 `已成交` 后：

- 客户状态会变成已成交。
- 成交金额会计入首页成交统计和销售排名。

## 8. 新建报价流程

有两种进入方式：

### 从客户详情进入

1. 打开客户详情。
2. 点击 `新建报价`。
3. 系统进入报价页面，并自动带入当前客户。
4. 生成或导出报价单后，可点击 `返回当前客户`。
5. 报价记录会同步保存到该客户下。

### 直接进入报价系统

1. 点击 `进入报价` 或打开 `/quote`。
2. 手动填写客户信息和报价内容。
3. 导出报价单。

## 9. 报价系统使用

报价页面主要分为：

- 报价基础信息
- 草坪产品
- 报价单参数显示
- 施工辅料
- 实时价格
- 报价单预览/导出

### 场地面积

可输入场地面积。报价面积、辅料用量、运费、施工费都会按该面积计算。

### 产品筛选

可按以下条件筛选：

- 产品类型
- 草高
- 密度
- 磅重
- 搜索货号、名称、草高、密度、基布、价格

草高支持类似：

- `50mm`
- `50MM`
- `50毫米`

### 加针功能

后台可设置产品默认 `加针价格`。

生成报价时：

1. 先把产品加入右侧 `产品明细`。
2. 在产品明细里填写：
   - 加针数
   - 每针加价
3. 单价会自动变为：原阶梯单价 + 加针数 × 每针加价。
4. 导出的报价单只显示最终针数。

示例：

- 原密度：15针
- 加针数：3
- 报价单显示：18针

### 报价单参数显示

可勾选是否在报价单显示：

- 草高
- DTEX
- 草丝
- 密度
- 针排
- 底布
- 抗老化

未勾选的参数不会在报价单显示。

### 辅料报价

辅料包括但不限于：

- 橡胶颗粒
- 石英砂
- 胶水
- 减震垫
- 接缝布/连接带
- 运动白草
- 其他辅料

辅料可按平方自动计算用量。

颗粒规则：

- 每袋 25kg。
- 如果需要 20kg，按 25kg 计算。
- 如果需要 110kg，按 125kg 计算。
- 最终换算为吨计价。

石英砂：

- 价格按吨计算。

### 包工包料套餐

可以选择套餐方式，例如辅料 A、辅料 B。套餐也可以在后台维护。

### 运费和施工费

运费和施工费按输入的平方计算。

可选择：

- 运费+施工费合并填写
- 运费、施工费分开填写

后期如需做运费模板，可以继续扩展。

### 图片

产品和辅料可以有默认图片。

图片来源：

- 后台上传的默认图片
- 报价时临时上传替换的图片

导出报价单时会显示对应图片。

## 10. 报价单导出

支持：

- PDF
- Word/RTF
- 打印

导出格式：

- A4 页面
- 按公文排版风格
- 尽量压缩到一页
- 总价、税费、产品信息、辅料信息按当前设置显示

注意：

- 如果没有税费，不显示税费。
- 如果有税费，显示税费。
- 导出的报价单里显示的是最终报价结果，不显示后台不需要给客户看的内部信息。

## 11. 管理后台

地址：`/admin`

后台主要分为：

- 产品管理
- 辅料管理
- 账号权限

### 产品管理

可维护字段：

- 货号
- 类型
- 名称
- 草高
- DTEX
- 加针价格
- 密度
- 针排
- 底布
- 抗老化
- 阶梯价格
- 图片
- 备注

功能：

- 新增产品
- 删除产品
- 批量删除
- 上传默认图片
- 导出标准表格
- 导入产品表格

### 产品类型自动生成

报价页面的产品类型按钮由产品数据自动生成。

如果导入表格中出现新类型，例如 `高尔夫草`，导入成功后报价页面会自动出现该类型按钮。

### 产品价格

产品支持阶梯价格，不是固定死价。

示例：

```text
50-1000平 19.5元/平
1000平以上 19元/平
```

报价系统会根据报价面积自动选择对应阶梯单价。

### 加针价格

后台产品管理中维护 `加针价格`。

例如：

- 加针价格：1元
- 报价时加 3 针
- 每平方单价增加 3 元

### 辅料管理

可维护：

- 辅料类型
- 名称
- 规格
- 单位
- 单价
- 默认图片
- 备注

功能：

- 新增辅料
- 修改价格
- 上传图片
- 删除辅料
- 批量删除

### 账号权限

主账号或有权限账号可维护：

- 新增账号
- 删除账号
- 修改账号名称
- 修改密码
- 设置角色
- 设置具体权限
- 启用/禁用账号

子账号：

- 可以修改自己的密码。
- 修改后会同步到主账号后台管理。

## 13. 图片管理

图片分两类：

### 默认图片

位置：管理后台。

适合：

- 产品固定图片
- 辅料固定图片

上线后后台上传的图片会保存到 R2，不会因为换电脑丢失。

### 临时图片

位置：报价页面。

适合：

- 某一次报价临时替换图片
- 不需要长期保存到产品默认资料里的图片

## 14. 数据保存说明

系统数据保存分为：

| 数据 | 存储位置 |
| --- | --- |
| 账号、权限 | D1 数据库 |
| 客户资料 | D1 数据库 |

## 15. 常见问题

### 1. 登录后反应慢

可能原因：

- 正在同步云端数据。
- 网络到 Cloudflare 较慢。
- 客户数据、图片、产品数据较多。

处理：

- 等待几秒。
- 刷新页面。
- 检查网络。

### 2. 页面显示旧内容

处理：

- Chrome 按 `Ctrl + F5` 强制刷新。
- 退出登录后重新登录。
- 如仍不行，让管理员检查是否已部署最新版本。

### 3. 新增账号登录不进去

检查：

- 账号是否启用。
- 密码是否正确。
- 是否已经保存后台数据。
- 是否存在中文账号输入法空格。

### 4. 导入后客户变成未命名客户

原因：

- 表格行没有客户名称，也没有联系方式。

现在系统会过滤完全空白行，但如果联系方式列名不规范，可能无法识别。

建议使用系统下载的模板。

### 5. 报价单没有显示图片

检查：

- 后台产品或辅料是否上传默认图片。
- 报价时是否临时上传图片。
- 图片是否上传成功。
- 网络是否能访问 R2 图片。

### 6. 普通销售看不到全部客户

这是正常权限设计。

普通销售只能看到自己的客户，主账号或管理员可查看全部。

### 7. 普通销售不能导出客资

这是正常权限设计。

普通销售只能下载导入模板，不能导出完整客户资料。

## 16. 日常建议流程

### 销售日常流程

1. 登录系统。
2. 查看自己的客户。
3. 新增客户或接收分配客资。
4. 在客户详情中记录跟进。
5. 需要报价时点击 `新建报价`。
6. 生成报价单。
7. 返回客户详情查看报价记录。
8. 成交后勾选已成交，填写成交价。
9. 如有合同，上传合同。

### 管理员日常流程

1. 登录系统。
2. 查看首页成交数据和新增客资。
3. 分配新客资。
4. 批量导入客资。
5. 检查销售成交排名。
6. 更新产品价格和辅料价格。
7. 管理账号权限。

### 产品价格维护流程

1. 进入管理后台。
2. 打开产品管理。
3. 搜索货号或类型。
4. 修改阶梯价格、加针价格、抗老化等。
5. 上传或更换默认图片。
6. 点击保存后台数据。
7. 到报价页面测试价格是否正确。

## 19. 最简培训话术

给销售培训时可以这样讲：

1. 先登录系统。
2. 客户都在客户管理里。
3. 每天跟进客户后，进客户详情写跟进记录。
4. 需要报价就点新建报价。
5. 报价完成后回到客户详情，报价记录会保存。
6. 成交后在报价记录里勾选已成交，填写成交价。
7. 客户要过几天联系，就添加提醒。
8. 不会操作的地方先不要乱删，找管理员处理。
